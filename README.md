# Cool Edit Mobile

A touch-friendly waveform editor in the style of the classic Windows audio editors, packaged as an Android app with Capacitor.

- Select, cut, copy, paste, trim, undo and redo on a zoomable stereo waveform
- Transform: amplify, normalize, fades, reverse, invert, echo, reverb, filter, equalizer, compressor, speed
- Generate tones and noise, statistics and frequency analysis
- **Rec**: records the audio other apps are playing (Android 10+, uses playback capture; some apps block it)
- **Mic**: records from the microphone into the open wave

## Getting the APK

Every push to the `cool-edit-android` branch builds a debug APK. Open the **Releases** page and download `app-debug.apk` on your phone, then allow "Install unknown apps" for your browser when Android asks. You can also run the workflow by hand from the **Actions** tab.
